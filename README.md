# ia-previdenciaria-notebooklm
Gêmeo digital e Segundo Cérebro de Luiz Barsi Filho desenvolvido no NotebookLM com engenharia de prompts avançada. O modelo atua sob lógica hermética para calcular o Preço Teto de ativos reais (Klabin, Santander, Banrisul) e aplicar o método BESST focado em dividendos e carteira previdenciária. Projeto criado para o Desafio de Projeto da DIO.
